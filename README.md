# ph-sss

[![npm version](https://img.shields.io/npm/v/ph-sss.svg)](https://www.npmjs.com/package/ph-sss)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Philippine SSS (Social Security System) number validation

## Installation

```bash
npm install ph-sss
```

## Functions

- `formatSSS` — Format SSS number to XX-XXXXXXX-X
- `validateSSS` — Validate SSS number format
- `generateRandomSSS` — Generate random SSS for testing
